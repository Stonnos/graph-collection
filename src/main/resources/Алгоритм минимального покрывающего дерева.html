АЛГОРИТМ МИНИМАЛЬНОГО ПОКРЫВАЮЩЕГО ДЕРЕВА

Этот алгоритм предназначен для решения задачи кластеризации объектов. Здесь мы не будем приводить математическую основу этой задачи.

Кластеризация — это процесс разбиения множества объектов на четко выраженные кластеры. Отметим, что алгоритм применяется как для количественных, так и для качественных показателей.

Входными данными алгоритма являются:

  • Количество кластеров
  • Матрица расстояний между объектами

Ниже приведен псевдокод процедуры MST_Clustering, где k — количество кластеров, D — матрица расстояний.

MST_Clustering(k,D)
1. Сформировать граф G, где веса ребер соответствуют элементам матрицы D
2. Построить минимальное остовное дерево T для графа G
3. Удалить из полученного дерева k - 1 самых длинных ребер,
5. Полученный лес представляет собой кластеры
6. return T

Время работы алгоритма составляет O(V^2logV).
