РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ

В программе реализовано пять видов представления графа:

  • Списки смежных вершин (HashSet)
  • Списки смежных вершин (TreeSet)
  • Списки смежных вершин (ListSet)
  • Списки смежных вершин (SortedSet)
  • Матрица смежности

Отличие заключается в выборе структуры данных для списков смежных вершин. Ниже приведены трудоемкости основных операций:

Операция / ПредставлениеHashSetTreeSetListSetSortedSetМатрица
Добавление вершиныO(1)O(1)O(1)O(1)O(V)
Удаление вершиныO(E)O(E)O(E)O(E)O(V^2)
Очистка графаO(V+E) для всех
Добавление/удаление ребраO(1)O(log(E/V))O(E/V)O(E/V)O(1)
Поиск ребраO(1)O(log(E/V))O(E/V)O(log(E/V))O(1)

Ограничения

  • Максимально возможное количество вершин — 40;
  • Формат имени вершины: Длина не более 10 символов, только цифры и символы русского алфавита;

Операции над графом

Программа поддерживает следующие операции: добавление/удаление вершины, добавление/удаление ребра, изменение веса ребра, удаление всех ребер, очистка графа, удаление исходящих/входящих ребер вершины v, видоизменение графа. Все эти операции выполняются с использованием мыши. Необходимые подсказки отображаются в текстовом поле под рабочей панелью.

Создание случайного графа

Пункт меню: Граф -> Создать случайный граф. В модальном окне нужно задать количество вершин и ребер, тип графа, тип представления и диапазон весов.

Загрузка графа из файла

Условия для файлов .txt:

  • В первой строке указывается тип графа: directed или undirected.
  • Имя вершины может содержать только числа, символы английского и русского алфавита.
  • Формат ребра: (имя_v1, имя_v2) или (имя_v1, имя_v2, вес).

Пример содержимого файла:

directed
a
b
c
(a,b)
(a,c)

Сохранение графа в файл

Пункт меню: Граф -> Сохранить в файл.

Настройки

В меню Настройки -> Скорость анимации с помощью ползунка можно регулировать задержку визуализации.

Алгоритмы на графах

Меню Алгоритмы -> Алгоритмы для [не]ориентированных графов. Результаты выводятся в новом окне. Для некоторых алгоритмов требуется предварительно указать стартовую вершину.

Матрица расстояний

В алгоритмах вроде минимального покрывающего дерева матрица читается из .txt файла:

  • 1-я строка: размер матрицы NxN (одним числом).
  • Последующие строки: строки матрицы.

Пример (4x4):

4
1 2 3 4
2 4 5 6
1 5 2 1
5 6 7 8
