ТОПОЛОГИЧЕСКАЯ СОРТИРОВКА

Топологическая сортировка — это такое линейное упорядочивание вершин ациклического орграфа, при котором для каждого ребра (u,v) вершина u располагается раньше v. Если граф не является ациклическим, то топологическая сортировка невозможна.

Ниже приведен псевдокод основной процедуры Topo_Sort_Main, которая выполняет топологическую сортировку вершин графа и возвращает стек вершин в порядке топологической сортировки.

Topo_Sort_Main(G)
1. for для всех v E V[G]
2.     do color[v] <- WHITE
3. Stack <- Пустое множество
4. for для всех v E V[G]
5.     if color[v] = WHITE
6.        then Topological_Sort(G,v,Stack)
7. return Stack

Ниже приведен псевдокод вспомогательной процедуры Topological_Sort, которая выполняет топологическую сортировку вершин графа.

Topological_Sort(G,u,Stack)
1. color[u] <- GRAY
2. for для всех v E Adj[u]
3.     do if color[v] = GRAY
4.          then print "Граф не является ациклическим!"
5.          else if color[v] = WHITE
6.                  then Topological_Sort(G,v,Stack)
7. Push(Stack,u)
8. color[u] <- BLACK

Время работы алгоритма составляет O(V+E).
