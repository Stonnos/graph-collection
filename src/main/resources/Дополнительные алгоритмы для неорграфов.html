МИНИМАЛЬНОЕ ОСТОВНОЕ ДЕРЕВО

Минимальное остовное дерево связного взвешенного неорграфа — это такое ациклическое множество ребер, соединяющих все вершины графа и имеющих минимальный суммарный вес. В данной программе для построения минимального остовного дерева используются алгоритмы Прима и Крускала, подробное описание и псевдокод которых приведены в [1, с 653].

СВЯЗНЫЕ КОМПОНЕНТЫ

Связной компонент неорграфа — это такое максимальное множество вершин, в котором каждая пара вершин u и v достижимы друг для друга.

Ниже приведен псевдокод процедуры Connected_Components, которая находит связные компоненты неорграфа и возвращает массив, в котором вместе с каждой вершиной хранится номер связной компоненты.

Connected_Components(G)
1. for для всех v E V[G]
2.     do color[v] <- WHITE
3.        component[v] <- 0
4. count <- 0
5. for для всех v E V[G]
6.     if color[v] = WHITE
7.        then count <- count + 1
8.             DFS(G,v)
9. return component

Ниже приведен псевдокод вспомогательной процедуры DFS, которая находит связные компоненты неорграфа.

DFS(G,u)
1. color[u] <- GRAY
2. for для всех v E Adj[u]
3.     do if color[v] = WHITE
4.          then DFS(G,v)
5. component[u] <- count
6. color[u] <- BLACK

Время работы алгоритма составляет O(V+E).

ПОИСК МОСТОВ

Мостом в связном неорграфе называется ребро, при удалении которого граф разбивается на две связные компоненты. Связный неорграф называется реберно-связным, если количество мостов равно нулю.
