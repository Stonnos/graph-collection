ПОИСК ГАМИЛЬТОНОВА ЦИКЛА

Гамильтонов цикл — это цикл, проходящий через все вершины графа ровно один раз.

В данном алгоритме используется поиск с возвратом. Ниже приведен псевдокод процедуры Gamilton_Tour, которая выполняет поиск Гамильтонова цикла в неорграфе G из вершины s и возвращает TRUE, если цикл найден, и FALSE в противном случае.

Gamilton_Tour(G,s)
1. for для всех v E V[G]
2.    do color[v] <- WHITE
3. List <- Пустое множество
4. for для всех v E Adj[s]
5.    do if Gamilton_Visit(G,s,v,V[G]-1,List) = TRUE
6.       then addLast(List,s)
7.            return TRUE
8. return FALSE

Ниже приведен псевдокод вспомогательной процедуры Gamilton_Visit, которая выполняет поиск Гамильтонова цикла в неорграфе G из вершины s и возвращает TRUE, если цикл найден, FALSE в противном случае. Параметр d предназначен для подсчета количества вершин, которые еще не пройдены.

Gamilton_Visit(G,s,u,d,List)
1. if u = s и d = 0
2.    then addFirst(List,u)
3.         return TRUE
4. color[u] <- GRAY
5. addFirst(List,u)
6. for для всех v E Adj[s]
7.    do if color[v] = WHITE
8.       then if Gamilton_Visit(G,s,v,d-1,List) = TRUE
9.               then return TRUE
10. removeFirst(List)
11. color[u] <- WHITE
12. return FALSE

Время работы алгоритма составляет O(V!).
