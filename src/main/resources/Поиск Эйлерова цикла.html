ПОИСК ЭЙЛЕРОВА ЦИКЛА

Эйлеров цикл в неорграфе — это цикл, проходящий через каждое ребро графа ровно один раз.

Условие существования: Эйлеров цикл существует тогда и только тогда, когда граф является связным и для всех v E G deg(V) mod 2 = 0 (степени всех вершин являются четными).

Ниже приведен псевдокод главной процедуры Euler_Tour_Search, которая выполняет поиск Эйлерова цикла в неор. графе G из вершины s и возвращает логическое значение TRUE, если цикл существует, и FALSE в противном случае.

Euler_Tour_Search(G,s)
1. для всех v E V[G]
2.      do if deg(v)mod2 != 0 или deg(v) = 0
3.            then return FALSE
4. Stack <- Пустое множество
5. Euler_Tour(G,s,Stack)
6. Push(Stack,s)
7. return TRUE

Ниже приведен псевдокод вспомогательной рекурсивной процедуры Euler_Tour, которая выполняет поиск Эйлерова цикла в неор. графе. В ходе выполнения процедура удаляет пройденные ребра, тем самым разрушая граф G.

Euler_Tour(G,u,Stack)
1.  while TRUE
2.     do if список смежных вершин Adj[u] не пуст
3.          then do v <- Первая вершина из Adj[u]
4.                  removeEdge(G,u,v)
5.                  Euler_Tour(G,v)
6.                  Push(Stack,v)
7.          else return
