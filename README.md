GRAPH COLLECTION v3.0
========================================

Описание
----------------------------------------
GraphCollection - система, предназначенная для работы с ориентированными и неориентированными простыми графами.
Она предоставляет возможность визуализации графов, а также построение и изменение графов в графическом режиме.
В системе реализовано большое количество самых известных алгоритмов для работы с графами, а именно: нахождение кратчайших
путей из одной вершины, нахождение кратчайших путей между всеми парами вершин, построение минимального остовного дерева,
поиск связных компонент, топологическая сортировка, вычисление метрических характеристик графа, поиск Эйлерова цикла и др.
Система поддерживает создание графов различных форм представления, возможность генерации случайных графов на заданное
количество вершни и ребер, а также возможность загрузки и сохранения графов в файл с расширением .json.
Возможность загрузки и сохранения графов в базу данных, а также сохранение текущего изображение графа в формате .png.
С помощью инструментария вы можете видоизменять граф, добавлять/удалять вершины, добавлять/удалять ребра, назначать
ребрам веса и т.д. Система обеспечивает выдачу результатов алгоритмов на текущей структуре графа в удобном
для пользователя текстовом виде. Некоторые из алгоритмов поддерживают визуализацию их результатов. Вы также можете
сохранять результаты алгоритмов в файл с расширением .txt.
В программе также присутствует справочная подсистема, которая реализованна в виде отдельного
окна и содержит следующие разделы:
- Руководство пользователя
- Описания и псевдокоды алгоритмов на графах

Необходимый софт
----------------------------------------
* jdk 21
* maven => 3.3.9

Инструкция по развертыванию
----------------------------------------

1. Необходимо собрать проект с помощью команды:
    
   mvn clean install
   
2. Запустить приложение с помощью exe-файла GraphCollection.exe, расположенного в папке /target.

Сборка дистрибутивов для приложения
----------------------------------------

1. Для создания дистрибутивов необходимо собрать проект с помощью команды:

    mvn clean install -Pbuild-artifacts
    
2. После сборки проекта в директории target будут лежать два дистрибутива graph-collection.zip (для windows), graph-collection.tar.gz (для linux)

Примечание: Для сборки артефактов используется плагин maven assembly plugin. Файлы assembly-linux.xml, assembly-win.xml содержат
конфигурации для создания дистрибутивов.
